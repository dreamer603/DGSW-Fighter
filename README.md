# DGSW-Fighter
## 실행 시 주의사항

1. 실행 전 brew로 libmediainfo를 설치하셔야 합니다.

2. 혹시 실행에 오류가 난다면 pygame, ffpyplayer, pymediainfo 모두 정상적으로 설치됐는지 확인해 주세요.

3. 그래도 오류가 나면 아마도 libmediainfo 환경 변수가 vsc에서 지정되지 않아서일 것입니다.
vsc 콘솔 창에서
export DYLD_LIBRARY_PATH=/System/Volumes/Data/opt/homebrew/lib:/opt/homebrew/lib:$DYLD_LIBRARY_PATH
를 입력하시면 정상적으로 실행됩니다.

## 게임 설명
하나의 기기로 플레이하는 2인용 대전 격투 게임입니다.

DGSW FIGHTER는 오락기에서 흔히 보이던 격투게임을 모티브로 했습니다.

플레이어블 캐릭터는 ‘Minho’, ‘Juhwan’ 두 명이 있으며, 두 플레이어가 한 명씩 맡아 플레이합니다.

게임은 5전 3승제로 진행되며, 먼저 3점을 획득하는 플레이어가 승리합니다.

## 기능
- pygame
    - 좌우 이동, 점프, 일반 공격 2개, 스킬 공격 1개가 존재합니다.
    스킬의 경우 일반 공격보다 위력이 세고 부가효과가 있으며, 쿨타임이 존재합니다.
    - 민호의 스킬은 스킬 명중 이후의 일반 공격들이 40% 확률 추가 데미지를 입힙니다.
    주환의 스킬은 상대를 반대쪽 벽으로 날리며 데미지를 주고 자신의 체력을 회복 또는 증가시킵니다.
    - 공격 방향이 자동으로 보정됩니다.
    - 히든 커맨드가 존재합니다. 
    히든 커맨드 발동 시 발동 라운드를 끝으로 게임이 종료됩니다.
- ffpyplayer, pymediainfo
    - 시작 화면에서 인트로 영상이 재생됩니다.
    - 시작 화면에서는 아무 키보드 키나 입력하면 게임 화면으로 넘어갑니다.
    아무 키도 누르지 않을 경우 인트로 영상이 끝나면 자동으로 게임 화면으로 넘어갑니다


## 조작법
- Minho
  - W : 점프
  - A : 좌측 이동
  - D : 우측 이동
  - E : 일반 공격 1
  - R : 일반 공격 2
  - D + R : 스킬
    
- Juhwan
  - I : 점프
  - J : 좌측 이동
  - L : 우측 이동
  - O : 일반 공격 1
  - P : 일반 공격 2
  - L + P : 스킬
